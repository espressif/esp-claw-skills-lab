# Number Puzzle

Tap a numbered tile next to the empty space to move it. NEW shuffles the board; the screen tracks your moves and elapsed time.

Launch from the device Launcher. Requires a touch display; a speaker is optional. Use the device Launcher's back action to exit.

Configure options in `launcher.json.args`; the defaults work without changes. `target_size` adjusts the board size. `run_time_ms` sets runtime in milliseconds, with `0` for continuous play.

A browser simulator is available. Audio and sensor behavior depend on the physical device; runtime validation of this API migration is still pending.
