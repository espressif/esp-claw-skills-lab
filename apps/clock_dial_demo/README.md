# MOMENT 时钟

暖白陶瓷与石墨深色双主题表盘，搭配金属边框、指针阴影和橙色秒针。横屏并排显示表盘与时间，方屏采用上下布局，160×160 小屏保留核心功能。

## 操作

- 右上角 LIGHT / DARK（小屏为月亮图标）切换主题，× 返回 Launcher。
- 按住并拖动表盘内部，体验轻微视差；松手自动回弹。
- 底部 CLOCK / FOCUS 切换时钟与专注模式。
- 专注模式未运行时，沿外圈旋转设置 5～60 分钟，每档 5 分钟。
- START 开始，PAUSE 暂停，RESUME 继续，RESET 恢复当前选择的时长。结束显示 DONE 和呼吸进度环，无声音提示。
- 切换主题或返回时钟不会停止倒计时；退出 App 后不保留计时。

## 运行要求

需要至少 160×160 的屏幕。正确时间依赖设备时间同步与时区配置，倒计时使用 `system.millis()`，不受校时影响。无触摸设备显示时钟，可通过运行时取消 App。

本站详情页可直接打开在线模拟器试玩。模拟器与设备运行同一份 Lua 脚本，无外部字体、图片、网络或音频依赖。

## 安装与启动

将完整的 `clock_dial_demo/` 包安装到设备 DATA 根目录下的 `apps/`，再通过 `publish_app` 发布。DATA 根目录应通过设备存储接口解析，不要固定为 `/fatfs`。安装时先写脚本与资源，最后写 `launcher.json`。从设备 Launcher 点击应用启动。

`launcher.json` 保存启动配置，内嵌 `catalog` 保存本站目录信息；本文件是使用说明。App 不需要 `SKILL.md`。

## 实现说明

单文件使用当前 `display.open()` 屏幕对象 API，以基础图元绘制表盘和矢量字形。默认单缓冲，表盘按区域重绘；动态时以 50 ms 间隔驱动，静止专注界面仅在状态或秒数变化时重绘。实际帧率取决于硬件与传输开销。

触摸按下时锁定操作对象，按钮在松开时生效，拖动不会误触点击；屏幕使用 `<close>` 管理生命周期。
